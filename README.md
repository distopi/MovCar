# 🚗 MovCar - Sistema de Aluguel de Veículos

O **MovCar** é uma plataforma web completa desenvolvida para o gerenciamento e simulação de aluguel de automóveis. O projeto foi criado como parte de uma disciplina de Desenvolvimento Web, unindo uma interface moderna e responsiva a um sistema robusto de gerenciamento de dados no back-end.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web, dividindo-se em:

### **Front-end**
*   **HTML5** & **JavaScript (ES6+)**: Estrutura e comportamento dinâmico da página.
*   **SASS**: Pré-processador para uma estilização mais inteligente, modular e limpa.
*   **Bootstrap**: Framework CSS para garantir total responsividade em dispositivos móveis e desktops.

### **Back-end & Banco de Dados**
*   **PHP**: Responsável pela lógica de negócios, sessões de usuário e comunicação com o servidor.
*   **SQL / MySQL**: Banco de dados relacional para armazenamento seguro de usuários, veículos e históricos de locação.

---

## 🚀 Funcionalidades Principais

*   **Painel do Cliente:** Cadastro, login e gerenciamento de perfil.
*   **Catálogo de Veículos:** Visualização de carros disponíveis com filtros por categoria, preço e especificações.
*   **Simulação e Reserva:** Sistema dinâmico para escolher datas de retirada/devolução e calcular o valor total do aluguel.
*   **Área Administrativa (Backoffice):** Tela para gerenciamento da frota (CRUD de veículos) e controle de reservas ativas.
